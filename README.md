  *FOOD DELIVERY ANALYSIS*

#PROJECT OVERVIEW
this project analyzes food delivery patterns, peak order period, and the impact of traffic and weather conditions on delivery delays.

#OBJECTIVE
-analyze delivery times
-study the impact of traffic and weather
-identify peak order times
-suggest ways to optimize delivery preformance 

#DATASET
data set is from kaggle and it contains innformation such as:
-traffic conditions
-weather conditions
-delivery method
-delivery distance

#TOOLS USED
-python notebook
-python built-in functions
-git & github

#KEY INSIGHTS
-peak orders occur in the evening
-high traffic significantly increases dilevery time
-rainy weather causes longer delays
